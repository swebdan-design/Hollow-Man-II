# HOLLOW MAN — Controls

| Input | Field | Menus |
|---|---|---|
| D-Pad | Move / face | Navigate |
| A | Interact (talk, search, read, open, operate); if nothing is in front, use equipped tool | Confirm |
| B | Melee strike (pipe / axe) | Back / cancel |
| Hold B, release | Charged heavy strike (2x damage, knockback, breaks Hector's guard) | — |
| START | Open / close pause menu | Close |
| SELECT | Cycle tool: none → Revolver → Bottle → Shadow → Bandage (only tools you have) | — |

**A-button priority:** person in front → sign/object in front → breathing wall hint → equipped tool.

**Pause menu:** Inventory · Casebook · City Map · Shadow Status · Save · Options · Return to Game.

**Inventory:** select a weapon to equip, Bandages to heal, Bottles/Revolver to equip as tool,
a key item to use it on whatever is in front of you.

**Stealth basics:** stay out of enemies' facing cone, use dark floors, throw bottles to
distract, strike unaware enemies from behind for an instant takedown.
